 # Valentine React Project 💖

A cute and interactive Valentine-themed web app built with React + Vite + Tailwind CSS.

## ✨ Features

- 💖 Floating heart animations
- 😄 Fun Yes / No interaction
- 🎁 Love reveal page
- 🔥 Glowing surprise button
- 💌 Hidden love message reveal
- ⚡ Fast performance with Vite
- 🎨 Styled using Tailwind CSS
- 🔀 Routing with React Router

## 🚀 How to Run Locally

```bash
npm install
npm run dev
